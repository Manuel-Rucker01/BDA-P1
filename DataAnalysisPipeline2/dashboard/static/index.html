About this dashboard

This dashboard proposes a portfolio using ML models under the hood. It is designed to help non-technical users understand and run the same pipeline an analyst would.

What the model does: It analyses many signals (price history, fundamental/alternative features, knowledge-graph embeddings) and ranks stocks by expected alpha. The top-K strategy concentrates on the highest ranked names; other strategies trade more conservatively.

Strategies:

  • Concentrated top-K: picks the top N ranked names and allocates by inverse volatility.
  • High-confidence long: only long positions with high model confidence.
  • Regime-filtered L/S: adjusts long/short exposure depending on detected market regime (bull/bear).

Important: This is a tool for research and paper trading. It is not investment advice. Models can be wrong; backtests may not represent live results. Use small sizes and paper accounts first.
